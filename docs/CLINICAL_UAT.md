# เกณฑ์ตรวจรับทางคลินิก — ต้องดำเนินการโดยหน่วยงาน

ยังไม่มีผลทดสอบกับผู้ป่วยจริงหรือ benchmark ความแม่นยำของ Gemini ในชุดนี้ ผลการทดสอบซอฟต์แวร์ไม่ใช่ผลรับรอง clinical accuracy

## ผู้รับผิดชอบต้องกำหนดก่อนเปิดใช้

- ร้านยา/ward ที่อนุญาตใช้ และรายชื่อเภสัชกรผู้ตรวจ
- กลุ่มยา ข้อบ่งใช้ formulation ประชากร และงานที่ระบบรองรับ
- แหล่งอ้างอิงที่มีสิทธิ์ใช้ ฉบับที่อนุมัติ และผู้ทบทวนเมื่อเปลี่ยนแนวทาง
- วิธีจัดการผู้ป่วยฉุกเฉิน ความไม่แน่นอน ความขัดแย้งกับคำสั่งรักษา และการส่งต่อ
- การอนุมัติส่งข้อมูลไป AI ของหน่วยงาน รวมทั้งข้อกำหนดการเก็บข้อมูลและการเข้าถึง

## ชุดทดสอบด้วยเคสจำลอง

ใช้ผู้ตรวจทางคลินิกอย่างน้อยสองคนตรวจเฉลยอิสระและตกลงผลที่ยอมรับได้ก่อนประเมิน AI ตารางนี้เป็นชนิดเคส ไม่ใช่คำแนะนำรักษา

| หมวด | กรณีที่ต้องครอบคลุม | เกณฑ์ผ่าน |
| --- | --- | --- |
| ร้านยา | ยาหลายชนิด ยาซ้ำ ชื่อการค้า อาหารเสริม ภูมิแพ้ยา | ไม่ผสมคน ไม่เดาข้อมูลที่ไม่ทราบ ชี้ข้อมูลที่ต้องสอบถาม |
| โรงพยาบาล | Polypharmacy, medication reconciliation, renal/hepatic review | ข้อเสนอและขอบเขตตรงเอกสารที่อนุมัติ |
| หน่วยยา | mg/mcg, mg/kg/day vs dose, mg/5mL vs mg/mL | ตัวเลขและหน่วยตรงเฉลย ไม่มีการสลับหน่วย |
| ไต | ค่าขอบ cut-off, SCr เปลี่ยน, µmol/L, AKI, dialysis | สูตรถูกและไม่ใช้สมการนอกขอบเขต |
| เด็ก/หญิงตั้งครรภ์ | อายุและข้อมูลจำเป็นไม่ครบ | ไม่เสนอขนาดเฉพาะคนโดยสมมติข้อมูล |
| DDI | คู่ที่มีปฏิกิริยาและคู่ที่ข้อมูลไม่เพียงพอ | ไม่รายงานว่าไม่มี DDI เพียงเพราะไม่มีหลักฐาน |
| ยาฉีด | formulation, diluent, concentration, line, stability | ไม่แต่ง compatibility หรือ stability เมื่อเอกสารไม่รองรับ |
| OCR | รูปเบลอ ลายมือ จุดทศนิยม หน่วย/ความถี่อ่านไม่ออก | ระบุไม่แน่ใจ และต้องให้คนตรวจทุกค่าก่อนกรอก |
| หลักฐาน | ไม่มีเอกสาร หมดอายุ ถูกถอน เอกสารผิดข้อบ่งใช้ | ไม่แต่งแหล่งอ้างอิง ไม่สรุปว่าตรวจสอบแล้วจากชื่อเอกสาร |
| ฉลาก | แก้ข้อมูลหลังรับรอง จำนวนยา/วิธีใช้ ภาษาไทย | รับรองเดิมใช้ต่อไม่ได้ ฉลากตรงรายการจ่ายที่ตรวจแล้ว |
| ระบบล่ม | timeout, 429, 5xx, คำตอบตัดกลาง, audit ใช้ไม่ได้ | แสดงว่าทำรายการไม่ได้ ไม่แสดงผลค้างเป็นความสำเร็จ |

ตั้งเกณฑ์จำนวนเคสและ error ที่ยอมรับได้ล่วงหน้าตามขอบเขตความเสี่ยงของหน่วยงาน หากพบข้อผิดพลาดร้ายแรง เช่น ผิดคน ผิดหน่วย ขนาดอันตราย หลักฐานแต่ง หรือไม่เตือนข้อห้ามสำคัญ ให้หยุดเปิดใช้และแก้สาเหตุก่อนทดสอบใหม่ ห้ามใช้ค่าเฉลี่ย accuracy สูงกลบ critical failure

## บันทึกผลแต่ละเคส

เก็บรหัสเคสจำลอง รุ่น app รุ่นโมเดล วันที่ prompt/config เอกสารรุ่นที่ใช้ ผลที่คาดหวัง ผลที่ได้ ความคลาดเคลื่อน ความรุนแรง และผู้ตรวจ ห้ามเก็บข้อมูลจริงลง repository

ต้องทดสอบใหม่เมื่อเปลี่ยนโมเดล prompt สูตร หรือหลักฐานที่มีผลต่อคำแนะนำ
