สร้างกุญแจเข้าใช้รายบุคคล

สำหรับผู้ดูแลระบบ กุญแจถูกสุ่มในเบราว์เซอร์ด้วย Web Crypto ไม่มีการส่งออกจากหน้านี้

ส่งกุญแจให้เจ้าของบัญชีเป็นการส่วนตัว ห้ามวางกุญแจหรือ API key ลง GitHub หากรั่วให้เปลี่ยน keyHash ใน USERS_JSON ทันที

กลับหน้าใช้งาน

กุญแจสำหรับผู้ใช้

ค่าตั้งฝั่ง Apps Script

นำ JSON นี้ใส่ Script Property ชื่อ USERS_JSON ถ้ามีผู้ใช้เดิมอยู่ ให้เพิ่ม object ใหม่เข้า array เดิม อย่าเขียนทับผู้ใช้อื่น

keyHash เป็น hash ของกุญแจ ระบบฝั่ง server ต้องเก็บเฉพาะ hash ไม่ใช่กุญแจนี้
